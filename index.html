Fang & Breakfast

cozy monster-hotel logic puzzle

Platform: RUN.world (web, mobile browser)Genre: cozy logic puzzleRole: solo designer & builder

Context: Entry for RUN.world's October Jam (theme: Monster Mash). Public and live.

The pitch: You run a hotel for monsters. Put every guest in the right room, turn the lights out, and enjoy the Monster Mash.

Build & gameplay video available on request

Core loop

  1. Read the guests' needs for the night.
  2. Assign each monster to a room so that every rule is satisfied.
  3. Trigger Lights Out.
  4. Watch the Monster Mash payoff sequence, then move to the next night.
Content & structure＋
  • 30 handcrafted levels with a gradual difficulty ramp.
  • A shared daily puzzle every night: the same challenge for every player, built for daily return and social comparison.
  • No energy system, no timers. The player sets the pace; the difficulty lives in the logic, not in pressure.
Design decisions＋
  • One verb (assign a room). Anyone understands the goal from one screen, which suits short mobile sessions and ad creatives.
  • Payoff after every solve. The Monster Mash scene turns a logic check into a reward moment and gives the game its personality.
  • Theme serves the rules. Monster traits (who can't sleep next to whom, who needs which room) make the constraints memorable and easy to read.
Post-jam roadmap (planned)＋
  • 5 new monster guests, each adding a new rule type.
  • Haunted Honeymoon: a premium chapter pack.
  • 285 new daily puzzles for a full year of daily content.
  • Long-term: a standalone iOS / Android release.

Fogbound Casebook

cozy Victorian AI-interrogation mystery

Platform: RUN.world (web, mobile browser); native Unity version in development for iOS / Android / SteamGenre: detective / narrative puzzleRole: solo designer & builder

Setting: London, 1890. Gaslight, fog, and a suspect who talks back.

Build & gameplay video available on request

Core loop

  1. Walk the crime scene and collect clues.
  2. Question suspects in your own words, by typing or speaking. Suspects answer conversationally.
  3. Catch the lies, link the evidence.
  4. Name the culprit.
Design decisions＋
  • Free-form interrogation instead of dialogue menus. The player's own questions are the core mechanic, which makes every session feel personal and makes "catching a lie" a real skill.
  • A different culprit for each player in the same case. Solutions can't be spoiled online, so players can share the case without ruining it, which helps word of mouth.
  • Cozy, no gore. A tea-loving landlady and an office cat named Inkwell keep the tone warm and widen the audience beyond hardcore mystery fans.
Production & next steps＋
  • Unity version in progress (Unity 6, 2D URP) for iOS, Android and Steam, built with an AI-agent pipeline (Claude Code + Unity MCP).
  • Monetization plan: additional paid case packs.

01 / About

About me.

I am a game designer and builder with a background in game localization, performance marketing and AI-assisted development. That mix shapes how I design:

  • From localization, I know how player-facing text, events and UI flows work inside a live mobile game. I currently localize a live mobile game from Lilith Games / Farlight (EN→VI) under strict glossary and QA rules.
  • From 3 years of running Meta and Google ads, I think about the first 5 seconds: the hook, the readable promise, and what makes someone tap "Install".
  • From AI-assisted development, I go from idea to a playable build in days, not months. I use Unity, Claude Code (with Unity MCP) and AI asset generation, so I can test more ideas and cut weak ones early.

What I care about as a designer

  • One clear player verb per game, readable in a single screenshot.
  • Short sessions, satisfying payoffs, no punishing friction (no energy walls, no timers unless they serve the fun).
  • Daily reasons to return that respect the player's time.
  • Shipping a playable version first, then tuning from real feedback.

03 / Process

How I work.

  1. 01

    Concept

    One-page pitch: player verb, hook, target player, what the ad looks like.

  2. 02

    Design docs

    Concise GDD: core loop, session flow, FTUE (first-time user experience), difficulty curve, content plan, tuning sheet.

  3. 03

    Prototype fast

    Playable build in Unity or web within days, using AI coding agents (Claude Code + Unity MCP) and AI-generated assets.

  4. 04

    Test & tune

    Play sessions, feedback rounds and QC after each round; cut what isn't fun, tune what is.

  5. 05

    Ship & iterate

    Publish, watch how players behave, plan content (daily puzzles, new chapters, live events).
